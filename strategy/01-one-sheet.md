# 01 — Ashwa One-Sheet: Whole-of-Society Grand Slam Offer & Value Stack

Status: working thesis v0.1 (2026-11-15). Every cell below is a **conjecture** until a field test in `05-conjectures-and-bets.md` supports it.

**Thesis in one line:** India's school-van network is a trust network that runs on daily repetition and has never been digitised. Whoever owns the **driver↔parent trust graph** in one dense school cluster at a time, at linear cost, gets geometric returns: referrals, then payments, then fleet finance, then adjacent commutes.

**Hormozi value equation, used in every row:** Value = (Dream outcome × Perceived likelihood) ÷ (Time delay × Effort & sacrifice)

## Table C — Hedge stack vs edge stack (summary; detail in `04-hedge-edge-stack.md`)

| Hedge stack (cap the downside) | Mitigation | Edge stack (uncap the upside) | Lever |
|---|---|---|---|
| **Catastrophic:** child safety incident on an Ashwa trip, child-location data breach, founder's job/IP conflict | Incident protocol, minimal data, security basics, contract check; keep the day job | **Network effects:** each driver brings 15–30 parents | Invite-first onboarding |
| **Fractional:** churn, leakage (parent pays driver off-platform), dead clusters | Make tracking the value (not the transaction); free on existing customers | **Referral loops:** driver→parent, parent→parent, driver→driver | WhatsApp share cards |
| **Geometric losses:** trust erosion compounding (one bad driver hurts the brand), founder burnout | Verification + suspension, sustainable weekly cadence | **Density compounding:** more vans per cluster → faster matches → more vans | Cluster-by-cluster focus (Zepto-style) |
| **Linear costs:** servers, maps, SMS/OTP, time | Free tiers, OSM/cheap maps, WhatsApp-first, cap spend per bet | **Data compounding:** trip history → credit → finance revenue | Partner lenders |
