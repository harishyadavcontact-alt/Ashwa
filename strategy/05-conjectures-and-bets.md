# 05 — Conjectures, Null Hypotheses & Pilot Bets (market as lab)

Status: v0.1. Method: Popper-style conjecture and refutation. Every belief is a conjecture with a **null hypothesis** we try to fail to reject. Each test is a capped **pilot bet**. A failure becomes a **pivot bet**, not a crisis.

**Rules**
1. Each conjecture is tested **in isolation** (one variable), even though the thesis is holistic.
2. Pass and kill thresholds are written **before** the test runs. No moving goalposts.
3. Each bet has a **cost cap** (₹ and hours). Hitting the cap without a result counts as a fail.
4. Prefer **pretotypes** (Savoia): fake door, Mechanical Turk (founder does it by hand), Pinocchio (non-working mock), provincial (tiny real launch), re-label.
5. Thresholds below are starting guesses. Adjust once, *before* running, then lock.
